# T.C. Ulusal Bulut Şekli Tespit, Tasnif ve Resmi Raporlama Merkezi

> “Bulut geçici, evrak kalıcıdır.”  
> — Kurum mottosu, 2026

Bu depo, gökyüzüne bakıp “şu bulut midye gibi” demenin resmi bir kuruma dönüştürülmüş hâlidir. Yazılım çalışır. Ciddiyet abartılıdır. Anlam isteğe bağlıdır.

## Ne yapar?

Komut satırından bir gözlem verirsiniz. Merkez size:

- evrak numarası
- resmi şekil adı
- yoğunluk yüzdesi
- idari karar

üretir. Meteoroloji değildir. Sanat da değildir. Biraz evrak, biraz hava.

## Kurulum

```bash
python3 tespit.py
python3 tespit.py -g "soldaki kabarık şey"
```

Bağımlılık yok. Python 3 yeter. Çay önerilir, zorunlu değildir.

## Örnek çıktı

```
T.C.
ULUSAL BULUT SEKLI TESPIT MERKEZI
----------------------------------------

Yogunluk : %64
Karar    : UST YAZI BEKLENMEKTEDIR
----------------------------------------
Not: Itirazlar yalnizca yagmurlu gunlerde kabul edilir.
```

## Kurumsal ilkeler

1. Her bulut bir yazışmaya konu olabilir.
2. Belirsizlik, ek dilekçe ile giderilir.
3. Güneş açıkken bile dosya kapanmaz.
4. Patates bu kurumun görev alanında değildir.
